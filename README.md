# Экспедиторская компания

Десктопное приложение на JavaFX 21: заказчики оставляют заявки на перевозку, экспедитор заключает договоры с заказчиками и перевозчиками, изменение и расторжение договоров проходит по согласию второй стороны.

## Возможности по ролям

| Роль          | Что доступно                                                                                                                                                                                                                                                  |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Заказчик      | создание, изменение, отмена и удаление заявок; поиск, фильтры по статусу и периоду, сортировка; подтверждение или отклонение предложенных договоров; запросы на изменение и расторжение; уведомления; оценка услуги экспедитора                               |
| Экспедитор    | все заявки и смена их статуса; договоры с заказчиками и перевозчиками (предложение, изменение, расторжение); заявки перевозчиков о сотрудничестве; уведомления; оценка доставки; свой рейтинг; статистика; просмотр таблиц базы данных; экспорт в CSV и Excel |
| Перевозчик    | заявки о сотрудничестве; подтверждение договоров; запросы на изменение и расторжение; уведомления; свой рейтинг                                                                                                                                               |
| Администратор | все возможности экспедитора; назначение и удаление экспедиторов                                                                                                                                                                                               |

## Запуск

Нужен JDK 21 или новее. Из папки проекта:

```bash
./mvnw javafx:run
```

На Windows в PowerShell: `.\mvnw.cmd javafx:run`. При первом запуске Maven скачивает зависимости, поэтому нужен интернет.

## Тестовые аккаунты

Пароль совпадает с никнеймом.

| Роль          | Никнейм                   |
| ------------- | ------------------------- |
| Администратор | `admin`                   |
| Экспедитор    | `forwarder`, `forwarder2` |
| Заказчик      | `customer`, `customer2`   |
| Перевозчик    | `carrier`, `carrier2`     |

Заказчика и перевозчика можно также зарегистрировать на экране регистрации.

## Подключение к серверу

Адрес и режим задаются в `src/main/resources/app.properties`:

```properties
api.mode=http
api.baseUrl=http://localhost:8080
```

## Структура проекта

```text
src/main/java/com/beta/expedition/desktop
├── App.java            точка входа
├── controller/         контроллеры экранов
├── service/            бизнес-правила и проверка данных
├── api/                интерфейсы доступа к данным и их реализации
├── session/            текущий пользователь
├── ui/                 общие компоненты: диалоги, валидатор, форматирование, навигация
└── model/              DTO и перечисления

src/main/resources/com/beta/expedition/desktop
├── view/               FXML-разметка экранов
└── css/                стили
```

Слои: View (FXML) → Controller → Service → Api.
